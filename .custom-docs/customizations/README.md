# 自定义修改记录

本目录记录 Tegical 团队对 Dify 项目的自定义修改历史。

## 📋 记录规则

每次进行自定义修改时，创建一个新的 Markdown 文件，文件名格式：

```
YYYYMMDD-修改简述.md
```

例如：
- `20251124-initial-customizations.md` - 初始 UI 定制
- `20251201-add-custom-logo.md` - 添加自定义 Logo
- `20251215-integrate-sso.md` - 集成 SSO 单点登录

## 📝 文件内容模板

每个自定义修改文件应包含以下内容：

```markdown
# [修改标题]

- **日期**: YYYY-MM-DD
- **版本**: release/X.Y.Z
- **提交**: commit hash
- **执行人**: 名字
- **影响范围**: [前端/后端/全栈]

## 修改原因

简要说明为什么要做这个修改。

## 修改内容

### 1. [修改项1]

**文件**: 文件路径

**修改前**:
\`\`\`
代码片段
\`\`\`

**修改后**:
\`\`\`
代码片段
\`\`\`

**说明**: 修改说明

### 2. [修改项2]
...

## 测试验证

- [ ] 功能测试通过
- [ ] Lint 检查通过
- [ ] 单元测试通过

## 升级注意事项

未来升级 Dify 版本时需要注意的点。

## 相关链接

- 相关 Issue/PR 链接
- 参考文档链接
```

## 💡 使用建议

1. **新增修改时**：
   - 创建新文件记录修改
   - 更新本 README 的"历史记录"表格
   - 更新"按类型查找"和"按组件查找"索引
   - 提交代码时引用文档

2. **查看修改时**：
   - 按日期或类型查找对应文件
   - 查看文件了解详细修改内容
   - 参考"升级注意事项"规划升级

3. **版本升级时**：
   - 查看所有历史记录文件
   - 确认哪些修改需要重新应用
   - 创建新的修改记录文件（如有调整）
