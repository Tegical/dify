# 自定义文档索引

## 文档列表

### 版本管理
- `version-upgrade.md` - Dify 版本升级指南，记录如何从一个版本升级到另一个版本并保留自定义修改

### 自定义说明

## 分支策略

当前采用的分支策略：
- `main` - Dify 官方主分支（仅跟踪）
- `release/X.Y.Z` - Dify 官方发布分支（仅跟踪）
- `dev` - Tegical 开发分支（基于 release/1.10.0 + 自定义修改）

## 使用说明

AI Agent 在执行任务前应先阅读本索引文档，了解项目当前状态和自定义内容。
